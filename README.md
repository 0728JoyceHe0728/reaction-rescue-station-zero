# Reaction Rescue: Station Zero

A story-driven chemistry game about balancing chemical equations.

After a meteor strike disables the Helios-9 space station's oxygen loop, players take the role of chemical engineer Mira Chen. Working with the station AI KEPLER, they adjust reaction coefficients to restore five critical systems before the rescue window closes.

## Course information

- **STEM topic:** Balancing chemical equations
- **STEM branch:** Chemistry
- **Format:** Five-round browser game with live atom counts and targeted feedback
- **Learning objectives:**
  1. Balance chemical equations by equalizing atoms of each element.
  2. Apply the law of conservation of mass.
  3. Distinguish coefficients from subscripts and use the smallest whole-number ratio.
